# gh-tools-sandbox-org

Sandbox repository used to test the GitHub tools for AI agents. It is safe to write here.
Everything created by tests is prefixed (`[A1]`, `[A2]`, `[A3]` titles, `a1/`, `a2/`, `a3/` branches).

Contents: a tiny Python package `calc` (`add`), unit tests in `tests/`, and a CI workflow (`test` job).

Run the tests: `python -m unittest`
